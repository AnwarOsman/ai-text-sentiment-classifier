# AI Text Sentiment Classifier

A beginner-friendly AI project that analyzes text and classifies its sentiment as Positive, Negative, or Neutral.

## Project Overview

This project uses Python and TextBlob to analyze the sentiment of English text.

The classifier calculates the sentiment polarity of a given sentence and returns one of three results:

- Positive
- Negative
- Neutral

## How It Works

The project takes a piece of text as input and analyzes its sentiment using TextBlob.

For example:

- "I love this course!" → Positive
- "This project is very difficult." → Negative
- "The course is okay." → Neutral
